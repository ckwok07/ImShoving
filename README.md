# A program to help you win more money...or lose more

A Python-based NLTH poker equity simulator.

The engine supports both deck-based random opponents and explicit opponent ranges, with correct blocker handling and tie splitting.

Still in development

#### Expected Value Calculation
Given an `equity` ($E$), pot ($P$), and call amount ($C_{amount}$) we can calculate the expected value ($EV$) with the following equation.

$$
EV = E \times (pot + C_{amount}) - C_{amount}
$$

#### Accuracy Calculation
Given `best_ev` ($EV_{best}$) and `chosen_ev` ($EV_{chosen}$) we calculate the players accuracy for that turn by creating a range [0,100] for which the `chosen_ev` will fall between.

We calculate the `ev_loss` ($EV_{loss}$) generated by the player with the equation 

$$
EV_{loss} = EV_{best} - EV_{chosen}
$$
