# A program to help you win more money...or lose more

A Python-based NLTH poker equity simulator.

The engine supports both deck-based random opponents and explicit opponent ranges, with correct blocker handling and tie splitting.

Still in development

#### Accuracy Calculation
Given `best_ev` ($EV^b$) and `chosen_ev` ($EV^c$) we calculate the players accuracy for that turn by creating a range [0,100] for which the `chosen_ev` will fall between.

We calculate the `ev_loss` ($EV_{loss}$) generated by the player with the equation 

$$
EV_{loss} = EV^b - EV^c
$$
